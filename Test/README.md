# Test

Source Han Sans JP Regular, a CID-keyed font with CFF outlines, for PDFjet's
tests of the CFF subsets: Adobe's SubsetOTF/JP edition of release 2.005R,
under the SIL Open Font License 1.1, in `SourceHanSansJP-LICENSE.txt`. IBM
Plex Sans, in `IBMPlexSans`, is the name-keyed CFF font the tests read.
